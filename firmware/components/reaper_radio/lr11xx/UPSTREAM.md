# Semtech LR11xx driver provenance

Unmodified files from https://github.com/Lora-net/SWDR001, commit a333238acfa0a9dee9ce2824ce52e89b98f3d24b (driver 3.0.0). Included only the radio, system and register-memory sources, the headers they need and LICENSE.txt. GNSS, Wi-Fi scanning, LR-FHSS, ranging, the crypto engine and the bootloader are excluded. Used by the T1000-E's LR1110 (D57).

License reviewed before reuse: Clear BSD, the same license as the SX126x driver in `../vendor/`. Keep source notices and reproduce LICENSE.txt in binary distribution materials.
