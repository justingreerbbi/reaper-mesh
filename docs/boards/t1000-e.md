# Seeed SenseCAP T1000-E

A credit-card-sized tracker with a built-in battery and antenna, an nRF52840 processor and a
Semtech LR1110 radio. It has no screen: you use it from the mobile app over Bluetooth or the
portal over USB. It is built with Zephyr rather than ESP-IDF (D57).

**Status:** experimental. It installs, keeps its settings, listens on the radio and pairs with a
phone; transmitting and links with the other boards are not tested yet. See
[Status](../overview/status.md).

| | |
| --- | --- |
| Firmware target | `t1000-e`, image `t1000e-reaper-mesh-v…` |
| Processor | nRF52840, 1 MB flash, 256 KB RAM |
| Radio | Semtech LR1110 (high-power PA) |
| Screen | None |
| Battery | Built in; voltage only, since there is no fuel gauge |
| USB | Native USB serial |
| Install | [Browser installer](../guides/flashing-firmware.md#seeed-sensecap-t1000-e), through the board's own bootloader |

## Using it

- **Button:** its only button is the main button. Holding it **5 seconds** opens Bluetooth pairing;
  the portal, connected over USB, shows the passkey.
- **Transmit power:** low −9 dBm, medium +7 dBm, high +22 dBm, at the radio chip. No boost.
- **Not used:** GNSS, the accelerometer, the light and temperature sensors, the buzzer and Wi-Fi
  scanning stay off.

## Developer details

Pins follow Seeed's T1000-E reference firmware and agree with RIOT's board support.

| Property | Value |
| --- | --- |
| USB | One CDC ACM serial port. Opening it at 1200 baud and closing it restarts into the bootloader's serial DFU mode, which the installer uses. The bootloader shows Seeed's USB ID, `2886:0057` |
| Radio | LR1110 on SPIM2: SCK P0.11, MOSI P1.09, MISO P1.08, NSS P0.12, reset P1.10, BUSY P0.07, IRQ P1.01. TCXO on DIO3 at 1.6 V; DIO5–DIO8 drive the RF switch (receive DIO5+DIO8, high-power PA DIO6+DIO8). Needs LR1110 firmware 0x0303 or later to set Reaper's sync word |
| Power | P1.06 turns on the 3.3 V rail at boot. GNSS (P1.11), the buzzer (P1.05) and the sensor rail (P0.04) are held off |
| Button and LED | Button P0.06, active high with pull-down; status LED P0.24, active high |
| Battery | P0.02 (AIN0) behind a 2:1 divider; USB power on P0.05 |
| Flash layout | SoftDevice S140 v7 `0x0` (kept for the bootloader), app `0x27000`, settings `reaper_nvs` `0xe2000` (16 KB), keys `reaper_keys` `0xe6000` (8 KB), Bluetooth `storage` `0xe8000` (8 KB). `0xea000`–`0xf4000` is the bootloader's reserved app-data area; the bootloader starts at `0xf4000` |
| Node ID | 48 bits of the chip's factory device ID. Bluetooth advertises a separate random address |
| Radio gate | `firmware/t1000-e/src/t1000e_profile.hpp`. Open on the development unit: the owner confirmed its US/915 MHz model and antenna on November 17, 2026 |

Never overwrite its bootloader or SoftDevice: they are what make browser installs and recovery
possible.
