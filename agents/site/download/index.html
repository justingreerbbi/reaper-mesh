Desktop app

Reaper Mesh on your computer.

The web portal and the firmware installer as an app for macOS, Windows and Linux. Plug in your radio over USB to message, map and manage it, or install its firmware. No browser needed.

Download formacOS Download forWindows Download forLinux

macOS 11 or later (Apple silicon or Intel), 64-bit Windows 10 or later, or 64-bit Linux. On Ubuntu and Debian you can also install the .deb package. Every version, with firmware files and checksums, is on the releases page.

First launch

Allow it once.

The app is not signed by Apple or Microsoft yet, so your computer asks before opening it the first time.

macOS

Drag Reaper Mesh to Applications and open it. If macOS says it can't check the app, open System Settings → Privacy & Security and choose Open Anyway.

Windows

Run the installer. If Windows shows "Windows protected your PC", choose More info, then Run anyway.

Linux

Make the AppImage executable (chmod +x Reaper-Mesh-Linux-x86_64.AppImage) and run it. To use USB without sudo, add yourself to the dialout group and log in again.

USB today, Bluetooth later

The desktop app connects to your radio over USB. For Bluetooth, use the web app in Chrome or Edge, or the mobile app. Its messages and settings stay on this computer, separate from your browser's.
