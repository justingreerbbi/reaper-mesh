Install Reaper Mesh firmware

Flash a board from your browser over USB. No software to install.

This browser can't talk to USB devices. Open this page in Chrome, Edge or Brave on a computer.

1Choose your board

Loading available firmware…

2Get ready

  • Plug the board into this computer with a USB data cable.
  • Close the web portal and any other app using the board.
  • Keep it plugged in until the install finishes, about a minute.

Your board's settings, Bluetooth pairings and team keys are kept. Only the firmware is replaced.
