Pairing a new device over Bluetooth

  1. Hold the main button on your device for 5 seconds to open pairing.
  2. Connect over Bluetooth, then pick the name your device shows, such as Reaper-1A2B.
  3. Type the 6-digit passkey from the device screen when your browser asks.

Over USB, nothing needs pairing. Choose the port when asked.

      Position

      What this device reports to other nodes.
      The device announces this browser's location while this page is open, so others see you move on their map. It updates after you move about 25 m, as often as the beacon timer allows.

      Announcing is off in Discovery, so others won't see updates until they ask. Turn it on to update their maps.

      Stops when this page closes, and keeps the last location.
      Saved position A fixed point on the device. It does not follow you.

      Locations go over the radio unencrypted, even on encrypted channels. Anyone in range can see them, and may keep them after you stop.

      Plugins

      Plugins add map types, fields and settings without changing the app. JSON definitions cannot execute code or send messages. Settings apply to this browser. Removing a plugin preserves map items.

      Storage

      This browser saves message history and pending changes before sending. If a connection is interrupted, uncertain work stays unknown and is never automatically resent. Export a backup before resetting history.

      Simulated device

      Models protocol replies only, not a radio. Arm one fault, change the device name, then save.

      PIN protection

      Optional. A PIN protects saved channel keys and locks the app when connected.

      Local data

      Messages, map items, keys and delivery records are stored in this browser. Without a PIN, keys are saved without a password. Cached map tiles are kept by the browser. This doesn't erase the device's inbox, other browsers or phones, or what others have received. Reconnecting may download messages the device still holds.

      Erase everything in this browser?

      This permanently removes local keys, PIN, messages and settings. All open Reaper Mesh tabs will disconnect. Device memory is unchanged; messages still on a device can return after reconnecting.

      Delete from this browser?

      This does not delete messages on devices or other users' apps, cancel transmissions, or change ACKs. Removed sent messages lose delivery-query recovery.
